# Простая офисная система талонов

Стек специально простой:

- Node.js
- Express
- EJS
- обычный CSS
- SQLite
- обычные SQL-запросы без ORM

## Что уже есть

- вход по логину и паролю;
- роль helper;
- роль staff;
- создание талона;
- ФИО;
- телефон;
- Telegram / Мой налог / Яндекс Про;
- общий список талонов;
- поиск;
- фильтр по статусу;
- фильтр по дате;
- сотрудник может присвоить номер;
- статус «Ожидает»;
- статус «Переведен на актив»;
- строки таблицы не кликабельные.

## Запуск

Нужен Node.js 20+.

1. Распакуй папку.
2. Открой терминал в папке проекта.
3. Установи зависимости:

```bash
npm install
```

4. Скопируй настройки:

Windows:

```bat
copy .env.example .env
```

macOS / Linux:

```bash
cp .env.example .env
```

5. Открой `.env` и обязательно поменяй `SESSION_SECRET` и пароли.
6. Запусти:

```bash
npm start
```

7. Открой:

```text
http://localhost:3000
```

## База

Файл базы автоматически создастся здесь:

```text
db/office.db
```

Схема лежит в:

```text
db/schema.sql
```

То есть никакого Prisma и миграционных фреймворков нет — обычный SQL.

## Как работает

Helper входит и создает талон.

Новый талон получает статус:

```text
Ожидает
```

Staff входит в список талонов, вводит номер и нажимает:

```text
На актив
```

После этого статус становится:

```text
Переведен на актив
```

## Дизайн

Все страницы оформлены в одном стиле: светлый градиентный фон, карточки со скруглениями, фиолетовый акцент, единая верхняя панель, адаптивная форма создания талона и аккуратная таблица. Визуальная основа страницы входа сохранена: логотип `ദ്ദി（• ˕ •マ.ᐟ`, подпись «Авторизация» и карточная форма.

## Автоматическая очистка талонов в 00:00

Таблица `tickets` автоматически очищается каждый день ровно в `00:00` по локальному времени компьютера/сервера, на котором запущено приложение. Пользователи, логины и пароли при этом не удаляются.

Если приложение было выключено в момент полуночи, при следующем запуске оно автоматически удалит талоны, оставшиеся от предыдущих дней.

Если сервер работает в другом часовом поясе, укажи нужный timezone перед запуском Node.js. Например на Linux/macOS:

```bash
TZ=Europe/Moscow npm start
```

Или добавь `TZ=Europe/Moscow` в `.env`. Замени `Europe/Moscow` на часовой пояс вашего офиса.
