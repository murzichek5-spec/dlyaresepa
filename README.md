# Простая офисная система талонов

Стек специально простой:

- Node.js 22
- Express
- EJS
- обычный CSS
- SQLite
- обычные SQL-запросы без ORM
- SSE для live-обновлений без Socket.IO

## Логика

1. Helper входит в систему.
2. Создаёт талон только по двум полям: ФИО и телефон.
3. После создания талон появляется ниже на той же странице.
4. Helper уже после создания отмечает:
   - Telegram;
   - Мой налог;
   - Яндекс Про.
5. Каждая галочка сразу сохраняется в SQLite.
6. Открытая страница Staff получает изменение в реальном времени и сразу меняет ✓ / — без ручного обновления.
7. Staff присваивает номер и переводит талон в статус «Переведен на актив».

Новые талоны также автоматически появляются у Staff: при создании сервер отправляет live-событие, и список обновляется.

## Запуск локально

```bash
npm install
cp .env.example .env
npm start
```

На Windows вместо `cp`:

```bat
copy .env.example .env
```

Открыть:

```text
http://localhost:3000
```

Перед реальным использованием поменяй `SESSION_SECRET`, `HELPER_PASSWORD` и `STAFF_PASSWORD`.

## База

SQLite создаётся автоматически:

```text
db/office.db
```

SQL-схема:

```text
db/schema.sql
```

Талоны автоматически удаляются каждый день в 00:00. Пользователи и пароли не удаляются. Если сервер был выключен в полночь, старые талоны будут удалены при следующем запуске.

## Render

В `render.yaml` закреплён Node.js 22.22.0, потому что эта версия нормально подходит текущей версии `better-sqlite3`.

Для теста можно использовать Free Web Service. Помни: без Persistent Disk локальный файл SQLite на Render может пропасть при redeploy/restart. Для постоянной рабочей базы нужен Persistent Disk или отдельная серверная SQL-база.
